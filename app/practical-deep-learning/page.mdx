# Foundation Concepts

*"Suppose we arrange for some automatic means of testing the effectiveness of any current weight assignment in terms of actual performance and provide a mechanism for altering the weight assignment so as to maximize the performance. We need not go into the details of such a procedure to see that it could be made entirely automatic and to see that a machine so programmed would "learn" from its experience."* - Arthur Samuel

## Concepts described in the above statement:

- The idea of a "weight assignment" 

- The fact that every weight assignment has some "actual performance"

- The requirement that is an "automatic means" of testing performance

- The need for a "mechanism" (i.e. another automatic process) for improving performance by changing the weight assignments

**Weights** are just variables and **weight assignment** is a choice of values for those variables.

A **model** is a the program that accepts inputs, a special kind of program that can do *many different things* depending on the weights; model inputs are generally referred to as *model parameters* whereas the term *weights* is reserved for a particular type of model parameter.

A means of automatic testing the effectiveness of any weight assignment in terms of performance would be how well the model performs, how many results were accurate.

Lastly a mechanism for altering weight assignment to maximize performance, usually human input, or more examples, which eventually leads to automatic adjustments and self learning models.
